🔧 Configuração inicial

Este painel acessa a sua própria conta do Google Drive, com o seu login. Para isso, o Google exige que você crie uma chave gratuita (Client ID) — leva uns 10 minutos e só precisa ser feito uma vez.

1. Acesse console.cloud.google.com e crie um projeto (qualquer nome).
2. Menu ☰ → APIs e serviços → Biblioteca → busque Google Drive API → clique em Ativar.
3. APIs e serviços → Tela de permissão OAuth → tipo Externo → preencha nome e e-mail → em "Usuários de teste" adicione o seu próprio e-mail do Google.
4. APIs e serviços → Credenciais → Criar credenciais → ID do cliente OAuth → tipo Aplicativo da Web.
5. Em "Origens JavaScript autorizadas" adicione o endereço onde esta página vai ficar (ex: https://seu-usuario.github.io) e também http://localhost para testar.
6. Copie o ID do cliente gerado e cole no campo acima.
